# Flutter Practice Project

A collection of Flutter development exercises and practical implementations created to explore, understand, and improve mobile application development using Flutter and Dart.

This project serves as a hands-on learning environment for practicing fundamental concepts, implementing common application features, and exploring Flutter development techniques.

## Features

- **Calculator** – Basic mathematical calculations.
- **Football Player Management** – Display and manage football player information.
- **Authentication** – Login and authentication interface.
- **Navigation** – Page navigation and route management.
- **State Management** – Managing application states using GetX.
- **Local Storage** – Storing application data locally.
- **Reusable Widgets** – Building reusable UI components.
- **Custom UI** – Practicing layouts, styling, and responsive interfaces.

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **State Management:** GetX
- **Local Storage:** GetStorage
- **Development Environment:** Visual Studio Code

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code or another IDE
- Android Emulator or a physical device

### Installation

1. Clone this repository:

```bash
git clone https://github.com/meizcalv890/latihan_flutter/
```

2. Navigate to the project directory:

```bash
cd flutter_practice
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
